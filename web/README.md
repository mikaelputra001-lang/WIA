# WIA Frontend

Aplikasi web untuk sistem pelaporan WIA.

## Teknologi
- React + TypeScript
- Vite
- React Router

## Setup

Install dependencies:
```bash
npm install
```

## Development

Jalankan dev server:
```bash
npm run dev
```

Aplikasi berjalan di `http://localhost:5173`

## Build

Build untuk production:
```bash
npm run build
```

Output di folder `dist/`

## Status

Saat ini menggunakan mock data dan localStorage untuk demo. Backend akan dikembangkan di branch terpisah.
